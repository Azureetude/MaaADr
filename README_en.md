## Feature List

- **Start Game**：
  - ✅Automatically start the game and claim daily rewards, receive emails (optional), and enter the main interface
- **Ethereum Exchange (Daily)**：
  - ✅Support daily exchange of copper for etheric goods (Energy Drink, Purple Gift Box, Battle Record IV, Dragon Coins)
- **Material collection**：
  - ✅Automatically navigate to the corresponding material level and use the *skip ticket*
- **Current activities**：
  - ✅During the current and rerun events, the bottom level will automatically use *skip tickets* to clear stamina (updated weekly)
- **Exchange event store**：
  - 🛠️In planning
- **One-click development**:
  - 🛠️In planning
- **Close game**:
  - ✅Exit the program after script execution is completed
